# Episode 1: Picking Your Parts

**Runtime:** ~12 min · **Goal:** viewer leaves with a compatible parts list and knows why each part fits.

## Parts and tools checklist
- [ ] All reference-build parts in boxes, lined up for the cold open
- [ ] Laptop with a parts-list site open (screen-recorded)
- [ ] Whiteboard or overlay template for the budget pie chart
- [ ] Tape measure (for case clearance demo)

## Script

**0:00 Cold open.** [WIDE] Boxes stacked on the desk. "Eight boxes. One working computer. By the end of this series, you'll build it yourself."

**0:20 What a PC actually is.** Walk the boxes in "data flow" order: the CPU thinks, RAM holds what it is thinking about, the SSD remembers everything long term, the GPU draws the picture, the motherboard connects them, the PSU feeds them, the case and cooler keep it all safe and cool.

**2:00 Set a budget and split it.** Start with the total, then split by percentage. Show the Math Box.

**4:30 The five compatibility checks.** One at a time, with an overlay checkmark each:
1. **CPU socket = motherboard socket** (AM5 with AM5, LGA1700 with LGA1700).
2. **RAM generation = motherboard memory type** (DDR5 boards don't take DDR4).
3. **Motherboard form factor fits the case** (ATX, micro-ATX, mini-ITX).
4. **GPU length < case GPU clearance**, and **cooler height < case cooler clearance**.
5. **PSU wattage is enough** ("that one gets its own episode").

**8:00 Clearance demo.** [CU] Tape measure on the GPU, then on the case. Read the spec sheet number on screen.

**9:30 Where not to save money.** PSU and storage. Cheap PSUs fail badly; cheap DRAM-less SSDs feel slow.

**11:00 Recap and teaser.** "Next time: how much power does this thing actually need? We're going to do the math."

## Math Box: splitting a budget

Example total: **$1,200**. A gaming-focused split:

| Part | Share | Dollars |
|------|-------|---------|
| GPU | 40% | 0.40 x 1200 = **$480** |
| CPU | 20% | 0.20 x 1200 = **$240** |
| Motherboard | 12% | **$144** |
| RAM | 8% | **$96** |
| SSD | 7% | **$84** |
| PSU | 7% | **$84** |
| Case + cooler | 6% | **$72** |
| **Total** | **100%** | **$1,200** |

Say on camera: "The shares have to add to 100 percent. If you move 5 percent to the CPU, it has to come out of something else."

Clearance rule, written as an inequality: **GPU length + 10 mm < case GPU clearance**. The 10 mm margin leaves room for the power cable bend.
