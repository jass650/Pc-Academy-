# PC Academy: Build Your First PC

A beginner DIY video series that takes a viewer from an empty desk to a working, stress-tested PC.
Every episode has a **script**, a **shot list**, and a **parts and tools checklist**. Where numbers
matter (power, bandwidth, storage, voltages) the episode includes a short **Math Box** that works the
numbers out step by step on screen.

## Reference build used on camera

All math in the series uses one mid-range example build so the numbers stay consistent.

| Part | Example | Key spec used in the math |
|------|---------|---------------------------|
| CPU | 8-core AM5 desktop CPU (e.g. Ryzen 7 7700X) | 105 W TDP, ~142 W package power limit (PPT) |
| Motherboard | B650 ATX | ~50 W |
| RAM | 2 x 16 GB DDR5-6000 | ~5 W per stick |
| GPU | RTX 4070 class | ~200 W board power |
| SSD | 1 TB PCIe 4.0 NVMe | ~7 W peak |
| Cooler | 240 mm AIO or tower air cooler | pump ~5 W |
| Case fans | 5 x 120 mm | ~3 W each |
| PSU | 750 W, 80 PLUS Gold, ATX 3.x | worked out in Episode 2 |

Swap in your own parts and rerun the Math Boxes; the method is the same.

## Shared conventions

- **[B-ROLL]** cutaway footage, **[OVERLAY]** on-screen graphic, **[CU]** close-up, **[WIDE]** wide shot, **[TOP]** overhead.
- Every episode opens with a 10 second cold open and closes with a "next time" teaser.
- Safety callouts get a yellow lower-third.
