The five compatibility checks

Before you buy

✓CPU socket = motherboard socket (AM5 with AM5)
✓RAM generation = board memory type (DDR5)
✓Board size fits the case (ATX, micro-ATX, ITX)
✓GPU and cooler fit the case clearances
✓PSU wattage is enough (Episode 2)
